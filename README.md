# CSP.guru
CSP.guru is an open-source database of concentrating solar power plants of the world for energy modelers and analysts.  This specific repository is intended to house regular updates to the database since the 2023 version and serve as the underlying dataset for the project-specific web pages available at [solarpaces.nlr.gov](https://solarpaces.nlr.gov)

## About
This datasets holds technical, economic, financial, and industrial data on all operating concentrating solar power stations and of stations under construction.

For more information on the data, its license, and contact information, open the [readme of the data package](./csp-guru/README.md).
